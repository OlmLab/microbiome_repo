Downloads & releases

Data package 1.26.0 (release R2026.31, built 2026-10-30).

About this page

Start with catalog_studies.parquet (one row per catalog study) and catalog_sample_metadata_wide.parquet (one row per sample); the evidence behind every value is in catalog_sample_determinations.parquet; the registry of every screened public study is registry_studies.parquet. Row counts are table rows: the catalog tables keep the rows retired in earlier releases (release_retired set) next to the current ones. Column definitions: data dictionary.

Whole package: data_package_v1.26.0.zip (193.6 MB) GitHub Release data-v1.26.0
