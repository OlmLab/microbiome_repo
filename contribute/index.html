Contribute

931 projects are missing basic sample information — age, country, health condition or subject. If you know where it is (you are an author, or the paper has a supplementary table), you can fill the gap in about two minutes.

1 · Find the project
Search the list below by accession, title word or author.
2 · Click “Share metadata”
A short GitHub form opens with the project already filled in (free GitHub account needed).
3 · Fill in four things
What you share · a link, or drag the file into the box · the column with sample IDs · tick the CC-BY box. Submit.

We check every submission and add the values in the next release; each value then links back to your issue as its evidence. A good table has one row per sample and a column with run (SRR/ERR…) or BioSample (SAMN/SAMEA…) accessions, for example:

SRR123456841malehealthy
