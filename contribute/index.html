Contribute

1,262 projects are missing basic sample information — body site, age, country, health condition or person id. If you know where it is (you are an author, or the paper has a supplementary table), you can fill the gap in about two minutes.

  1. 1
    Find the project

    Search the list below by accession, title word or cohort.

  2. 2
    Click “Share metadata”

    A short GitHub form opens with the project already filled in (free GitHub account).

  3. 3
    Fill in the form

    Four short questions, then tick the CC-BY box.

Already complete? Open the project page and use Mark it human-verified to record that a person checked it.

We check every submission and add the values in the next release; each value then links back to your issue as its evidence. A good table has one row per sample and a column with run (SRR/ERR…) or BioSample (SAMN/SAMEA…) accessions, for example:

Runage_yearssexcondition
SRR123456734femaleulcerative colitis
SRR123456841malehealthy

Something else wrong on a page? Use Flag an issue, or open the project (Projects) and use the link on its page. See the contributions people have already sent.
