1.18.2 — 2026-10-09 (release R2026.22, owner audit of empty projects and of split deposits)

  • Catalog projects without samples removed (25). A catalog project must now have at least one catalog sample (build_gut_scope, logged as empty_projects_dropped in the scope summary). Removed: 20 umbrella children whose single BioSample is catalogued under the parent BioProject (MetaHIT subject projects under PRJNA33049; PRJEB80526 → PRJEB101484; PRJNA871195 → PRJNA869587; PRJNA888226 → PRJNA880658); PRJEB39960 (all 87 BioSamples are mouse recipients of human faecal microbiota; registry host set to no by a curator-audit override); PRJNA1401443, SRP005975 and SRP006081 (no harvestable runs in the registry run table: Salmonella isolate genomes with mislabelled metagenomes, an SRA-only culturomics record, gnotobiotic-mouse culture collections). All stay in the registry.
  • Study groups. BioProjects that are deposits of one study (per-subject deposits, split or top-up deposits, identical records, a shared own-data paper) are linked by gut_studies.study_group_id / study_group_basis / study_group_members / study_group_n_samples (config/study_groups.csv; 55 groups proposed from identical records, title templates, near-identical titles of one submitter and shared papers, each partition confirmed by two independent reasoning-model replicates with a verified quote; 51 groups / 123 projects remain after the empty-project rule). Project pages show the group with links; the Project sheet marks grouped projects and filters a group with ?group=<id>. Projects stay accession-keyed (no merge).

1.18.0 — 2026-10-09 (release R2026.20, owner review of 1.17.1 + external coverage report)

  • Pooled BioSamples split into run units. 26 BioSamples (26 projects) that each held many distinct stool libraries under one BioSample accession (e.g. PRJNA398187: UC1–UC16 / CD1–CD3 / HT1–HT3 all under SAMN11885869; PRJNA1219367: 358 libraries under SAMN46555814) now give one sample per sequencing run (sample_key = run accession, sample_unit = run, biosample_accession kept): 1,441 run samples replace 24 BioSample rows. Rule: >= 5 DNA runs, all library names distinct after stripping lane / read / platform suffixes, and the BioSample holds >= 50 % of the project's runs or the project has <= 3 BioSamples (build_gut_scope.split_pooled_biosamples). Values written on the shared BioSample record are not copied to the run units.
  • 53 projects brought into the catalog (10,653 samples) after a two-replicate reasoning-model review of 101 registry studies whose runs look like human gut shotgun metagenomes but were classified out (config/registry_overrides.yaml, stage curator_audit; quotes in each entry): mostly assay recorded as other (library strategy OTHER / WGA on random metagenomic runs) or site unknown, a few host no. Includes PRJEB63587 (1,519 Bangladeshi infant samples) and PRJEB66487 (225; ENA base counts are 0 but the submitted FASTQs are 2.3–2.8 GB each). 41 reviewed studies stay out (in-vitro gut models and faecal cultures, animal hosts, environmental or mock material, isolates, gastric), 8 are unresolved.
  • Extra samples of infant-extension projects. Registry samples that the infant curation did not cover (later deposits, other time points, maternal samples) now enter through the registry route (3,186 samples in 14 projects, e.g. PRJNA1249435 315 → 1,109). The curated infant row still wins for every BioSample it covers; in_infant_catalog is now per sample (true only for curated infant rows).
  • 17,969 + 225 BioSamples harvested (registry_biosample_attributes) and 453 new attribute pairs normalised; the host / control scan of the new records removed 1,329 samples (config/sample_exclusions.csv: extraction / kit / PCR blanks, ZymoBIOMICS and other positive controls, wastewater, mouse, chicken, sea slug, soil, synthetic).
  • Sandpiper community composition on every profiled project page: gut_sandpiper_study_panels.parquet (mean relative abundance of the top 12 genera over the project's profiled gut samples, low-depth / non-metagenome profiles left out; 2,028 projects), drawn as a full-width stacked bar.
  • Known gap: the new samples carry archive (R1) values only; they have not been through the deep paper / supplement annotation of R2026.18, and the run-unit samples of split BioSamples have no Sandpiper profile yet (profiles are keyed by BioSample).

  • Deep per-sample annotation of all 2,837 gut projects. Every project was re-read from every source we can reach: all BioSample attributes (not only the mapped keys), sample titles / aliases / library names decoded into subject, time point, group and arm with two independent reasoning-model replicates that must agree (gut_r1_deep_v1), supplementary tables joined on sample, run, alias or subject identifiers (gut_r2_deep_v1), article body tables (gut_r3_tables_v1), and cohort-wide statements from newly linked papers (gut_r3_newlink_v1, gut_r4_newlink_v1). New values fill gaps only (never replace an equal or higher-ranked route). Sample coverage, 1.16.0 → 1.17.0: subject id 34.3 → 54.2 %; time point 13.5 → 30.0 %; exact age 26.3 → 28.6 %; sex 30.8 → 32.8 %; health condition 39.6 → 48.3 %; BMI 8.4 → 9.0 %; antibiotics 16.9 → 19.4 %; collection date 62.9 → 74.4 %; intervention arm 3.5 → 8.4 %; medication 0.7 → 1.6 %; diet 0.7 → 2.5 %; smoking 0.8 → 2.1 %. Where a new value and a published one both exist they agree for sex 99.9 %, country 99.8 %, exact age 98.9 % (± 15 days / 5 %), BMI 100.0 % of 141,369 / 448,327 / 116,791 / 39,208 compared samples. Evidence for every value is in gut_sample_determinations (evidence_source / locator / quote / parse_note).
  • Per-project source flags (gut_studies.src_archive, src_abstract, src_fulltext, src_supplement, src_external, src_contribution, src_expert = used / checked / none, with src_detail JSON). Current counts — archive {'used': 2751, 'checked': 115}; abstract {'checked': 1622, 'used': 928, 'none': 316}; full text {'none': 1002, 'used': 984, 'checked': 880}; supplementary tables {'none': 1313, 'checked': 1239, 'used': 314}.
  • Paper links: 466 new study × paper links for 401 projects that had none (accession search in Europe PMC full text and NCBI BioProject links, then title / description search judged by a reasoning model; registry_study_papers.source = paper_search_verified).
  • Scope corrections from the deep pass: a catalog-wide BioSample host / organism scan removed 7,150 non-human, environmental and mock-community samples (config/sample_exclusions.csv, reason host_nonhuman / other, with the attribute quoted); 18 projects leave the catalog because no human gut sample remains or because their runs are 16S amplicon data deposited as metagenomes (PRJDB19255, PRJEB39960, PRJEB70509, PRJNA1155655, PRJNA1190698, PRJNA1209134, PRJNA1213876, PRJNA1245131, PRJNA1305438, PRJNA1433968, PRJNA1472735, PRJNA1514052, PRJNA428537, PRJNA450709, PRJNA596121, PRJNA769748, PRJNA804967, PRJNA976196; config/registry_overrides.yaml, stage curator_audit).
  • Model-written short titles (≤ 60 characters) and one- or two-sentence descriptions for every project (gut_studies.short_title, short_description, short_description_model), from the archive record, the linked abstract and the curated sample facts; labelled as machine-written on the site.
  • Known limits: Europe PMC delivered supplementary archives at roughly 20–600 KB/s during this pass, so many supplements were not read (flag src_supplement = none; listed on the Contribute page under "supplementary tables not accessible to us"); PDF-only supplements are not parsed; medication / diet / lifestyle attributes are mostly finer-grained than the vocabularies and stay unmapped.
  • Site: project pages and every page header redesigned in the home-page style; per-project source checkmarks; at-a-glance panel with a globe of sample origins, depth and timeline sparklines; field coverage lists only fields the project has; sample tables load client-side with every metadata column the project has; Project sheet with narrow columns, short titles, source columns and filter; Contribute filters for missing supplements / full text.
