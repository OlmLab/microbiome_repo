Details
Archive description

This project profiles cervical microbiome composition in 50 patients across disease stages (benign/CIN/cancer) using low-coverage whole genome sequencing (LC-WGS).Data includes microbial reads after host DNA removal. Goals: (1) Identify stage-specific microbial signatures (2) Discover diagnostic biomarkers.
