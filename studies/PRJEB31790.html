Archive description

In this study, we tested metabolism of four drugs (dexamethasone, diltiazem, famciclovir and norethindrone acetate) by 28 healthy human gut communities. Community composition was determined with metagenomic sequencing. Analysis schemes, code and data of this study are available on GitHub (https://github.com/mszimmermann/drug-bacteria-gene_mapping)
