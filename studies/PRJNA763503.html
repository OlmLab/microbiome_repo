Details
Archive description

Here we present a pilot longitudinal data for the study of FMT application combined with the anti-inflammatory therapy in CD (n = 8) and UC (n = 6) patients. Data was obtained using the shotgun sequencing of patients stool samples (n = 56).

How this project entered the registry
