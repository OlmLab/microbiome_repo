Archive description

This project contains shotgun metagenomic sequencing data generated from stool samples collected as part of the CHILD Cohort Study to investigate early-life gut microbiota and health outcomes.

How this project entered the registry

Classified as human gut / stool shotgun DNA metagenome of infant / toddler and child by deterministic_prior with confidence 0.90. Assay shotgun_dna.
