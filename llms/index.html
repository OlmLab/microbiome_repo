For LLMs & API

Ask an AI assistant to search the catalog for you. Paste the prompt below into ChatGPT, Claude, Gemini or any assistant that can open web links, then add your question at the end.

Prompt to paste 
Refer to https://microbiome-repo.colorado.edu/llms.txt for instructions on how to access the Microbiome Repo. My question:

Example questions: probiotic trials where both treated and placebo samples have metagenomes · ulcerative colitis FMT projects · adult colorectal cancer cohorts with healthy controls · infant samples from Finland with exact ages.

How the search works

  1. Start from a ready-made selection. Small files list the projects for one intervention, health condition or age group:
    • by intervention: fmt · probiotic · prebiotic_or_fibre · synbiotic · live_biotherapeutic · antibiotic · diet_intervention · dietary_supplement · drug_therapy · surgery · bowel_preparation · exercise · vaccine · phage_therapy · other_intervention
    • by age: neonate · infant · child · adolescent · adult · elderly
    • by health condition (one file per code in api/vocabularies.json): allergy_or_atopy · autoimmune_inflammatory · cardiometabolic_other · colorectal_adenoma · colorectal_cancer · crohns_disease · gi_infection_or_diarrhoea · healthy_control · ibd_or_gi_disease · ibd_unspecified · ibs · intervention_cohort · kidney_disease · liver_disease · malnutrition · nec · neurological_psychiatric · obesity · other_cancer · other_disease · other_infection · pregnancy_postpartum · preterm_nicu · sepsis_or_infection · transplant_or_immunocompromised · type1_diabetes · type2_diabetes · ulcerative_colitis
  2. Combine. Every project record has the same keys — e.g. take by-intervention/probiotic.json and keep projects whose health_conditions include crohns_disease: that is "Crohn's + probiotic".
  3. Open the samples. api/samples/<ACCESSION>.csv lists every sample with its arm (intervention: probiotic / placebo / no_intervention …), condition, age, country and sequencing depth.

The same filters are on the Projects (health condition × intervention × design × "treated & control arms") and Samples.

Endpoints

filecontents
llms.txtplain-text instructions an assistant reads first (the prompt points here)
api/index.jsonendpoint list, meaning of every key, counts
api/vocabularies.jsoncodes and labels: health conditions, interventions, designs, age categories
api/projects.jsonall 5,086 projects (≈ 2 MB; better for scripts)
api/by-intervention/<code>.json · api/by-condition/<code>.json · api/by-age/<category>.jsonthe selections above
api/samples/<ACCESSION>.csvper-project sample sheet (plain CSV, key columns)
data/catalog_sample_metadata_wide.parquetevery sample, every field (for DuckDB / pandas / R)
data/catalog_studies.parquetone row per project
Downloads & releasesthe whole data package and every table

The API is a set of static files regenerated with every release (release R2026.43); URLs are stable. No key and no rate limit. Values are evidence-linked claims — the evidence for each is on the project page.
