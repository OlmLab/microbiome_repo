Cohorts (120)

A cohort is a set of projects that belong to the same study: projects described by one paper, or projects a curated cohort record lists together.

About this page

296 of the 5,086 projects belong to one of these 120 cohorts; the rest are single projects. Each cohort page lists its projects with sample counts, the shared papers and a merged sample download. The grouping is recomputed at every release; the list is in catalog_cohorts.csv. A paper groups projects only when it describes the data of two to four of them, or cites two to four projects that one centre submitted.
